# Project Constitution（项目长期工程原则）

1. **深模块优先**：复杂实现隐藏在模块子目录内，对外只暴露最小稳定入口；拒绝无策略价值的纯透传薄层。
2. **先减后加，零双轨腐化**：重构或演进旧能力时同步清理旧入口与死分支；绝不在仓库留下「同一件事的新旧两套写法」。
3. **门禁优先于文档**：凡能用静态类型、Linter、`dependency-cruiser` 或自动化测试拦截的错误，必须固化为编译/CI 红灯，不靠口头提醒。
4. **测试测行为，不测实现细节**：通过公开入口与最高层测试接缝断言外部行为，内部重构不破坏测试。
5. **最小依赖与可逆决策**：无充分理由不引入新第三方库；重大不可逆架构取舍必须沉淀进 `docs/adr/`。
